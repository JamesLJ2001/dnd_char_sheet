# 中世纪主题图片需求清单

## 需要的图片

请将以下图片放到 `web/public/images/` 目录下：

### 1. 地下城石墙背景
- **文件名**: `dungeon-wall.jpg`
- **用途**: 整个页面的大背景
- **要求**: 深色石墙纹理，地下城风格，不要太亮
- **尺寸**: 建议 1920x1080 或更大
- **搜索关键词**: "dark dungeon stone wall texture", "medieval stone wall"

### 2. 真实木纹纹理
- **文件名**: `wood-texture.jpg`
- **用途**: 卡片背景、按钮、木框
- **要求**: 真实的木板照片，深色木头，复古感
- **尺寸**: 建议 800x600 或更大
- **搜索关键词**: "dark wood plank texture", "medieval wood floor", "old wood texture"

### 3. 羊皮纸纹理
- **文件名**: `parchment-texture.jpg`
- **用途**: 文字区域背景
- **要求**: 米黄色羊皮纸，有自然的纹理和做旧感
- **尺寸**: 建议 800x600 或更大
- **搜索关键词**: "parchment paper texture", "old parchment texture", "aged paper texture"

### 4. 铁栅栏/铁艺装饰（可选）
- **文件名**: `iron-border.jpg`
- **用途**: 边框装饰
- **要求**: 黑铁栅栏或铁艺装饰纹理
- **尺寸**: 建议 500x500 或更大
- **搜索关键词**: "iron fence texture", "medieval ironwork texture"

## 推荐图片来源

- Unsplash (https://unsplash.com) - 免费高质量图片
- Pexels (https://pexels.com) - 免费商用图片
- Pixabay (https://pixabay.com) - 免费图片和纹理

## 注意事项

1. 图片格式: JPG 或 PNG
2. 避免过于鲜艳的颜色，选择深色、复古风格
3. 纹理图片可以平铺使用（seamless texture 更佳）
4. 文件大小建议控制在 1MB 以内以保证加载速度
